# Security Policy

## Supported Code

Security fixes go into the latest code on `maintenance/dependencies-startup`. Older branches and saved snapshots do not receive separate fixes.

## Reporting a Vulnerability

Open this repository’s **Security and quality** tab, select **Advisories**, and click **Report a vulnerability**.

Include:

- The branch or commit you are using.
- A description of the problem and what someone could do with it.
- Steps to reproduce it.
- Logs or a small test case that demonstrates the issue.

Remove live credentials and personal information from anything you attach. This includes Discord bot tokens, database passwords, and encryption keys.

Keep exploit details in the private report while the issue is being investigated.

## Review and Updates

I maintain this project as time allows and cannot promise a response or repair deadline. I’ll use the private report to ask questions and post progress updates.

For confirmed vulnerabilities, I’ll work on a fix or provide a workaround where one is available. If I close a report without a fix, I’ll explain why.

Please coordinate public disclosure with me so affected users have time to update.
